우리들의 리그 오브 레전드 전적을 공유하고 소통하는 미니 SNS 앱

단순 전적 조회를 넘어, 친구들의 전적 피드를 보고 피드백(훈수), 감정 표현, 플레이 소감을 공유하는 커뮤니티 형성

모바일 앱 (세로 모드 전용, iOS/Android 대응 여부는 개발 단계에서 결정)

3필요한 페이지 목록

✓1. 로그인/회원가입 페이지

기능이메일+비밀번호 로그인/회원가입, 자동 로그인(토큰 저장), Riot ID(소환사명+태그) 연동 및 인증

특징만 14세 미만 가입 제한(생년월일 검증), 롤 계정 매핑, 로그인 성공 시 메인 피드로 이동, 이용약관/개인정보처리방침 동의 절차 포함

✓2. 메인 페이지 (홈 / 피드 화면)

기능상단 전적 검색창, 팔로우/즐겨찾기한 친구들의 최근 게임 전적 피드(세로 스크롤)

특징전적 카드 자동 업데이트, 승/패 배경색 구분, 요약 데이터 및 좋아요/댓글 수 표시, 빈 피드 안내 문구와 친구 찾기 버튼

✓3. 게시물 목록 페이지 (전적 탐색/모아보기)

기능전체 공개 유저들의 '인생 경기'/'피드백 요청' 매치 모아보기, 카테고리 필터(솔로랭크/자유랭크/칼바람)

특징이슈 전적 카드 리스트 탐색, 필터 결과 없을 때 빈 상태 UI 제공

✓4. 게시물 상세 페이지 (매치 상세 + 피드백/댓글)

기능매치 10인 전체 전적(딜량 그래프, 아이템 빌드, 룬, 킬관여율), 댓글/피드백 작성 및 조회

특징작성자 소감 글과 라이엇 상세 데이터가 함께 조회, 부적절한 댓글/게시물 신고 버튼 제공

✓5. 게시물 작성 페이지 (전적 공유하기)

기능내 최근 매치 1개 선택, 한 줄 소감/피드백 요청글 작성, 공개범위 선택(전체공개/친구공개/비공개)

특징최근 게임 목록을 픽커(Picker) 형태로 제공, 등록 완료 시 피드/상세 페이지로 이동

✓6. 마이페이지

기능연동 롤 계정 프로필(티어, 주 챔피언, 승률), 내 전적 피드 모아보기, 팔로잉/팔로워 관리, 계정 설정

특징티어 변화 추이 및 최근 플레이 스타일 요약 카드 제공

✓7. 전적 검색 결과 페이지 (일반 검색)

기능임의의 소환사 입력 시 종합 전적 및 최근 매치 리스트 조회

특징OP.GG 방식의 기본 전적 제공 페이지, 존재하지 않는/비공개 전적 유저 조회 시 안내 메시지

✓8. 알림 페이지신규

기능팔로우, 댓글/피드백, 좋아요·감정표현, 승급/티어 변동 등 알림을 모아 보여주는 목록 화면

특징상단 앱 바 벨 아이콘으로 진입, 읽지 않은 알림 뱃지 표시, 탭 시 관련 게시물/프로필로 이동

✓9. 랭킹/리더보드 페이지신규

기능팔로우한 친구 간 주간 KDA/딜량 랭킹, 최근 24시간 최고 딜량·최고 KDA 하이라이트

특징3차 개발 항목(친구 하이라이트 뱃지, 주간 랭킹)의 실제 화면, 마이페이지/메인 페이지에서 진입

✓10. 친구 검색/팔로우 관리 페이지신규

기능닉네임/소환사명 검색 후 팔로우, 팔로잉·팔로워 목록 조회 및 언팔로우

특징마이페이지 "팔로잉/팔로워 관리"에서 진입하는 상세 화면으로 분리

✓11. 설정 페이지신규

기능알림 수신 on/off(항목별), 라이트/다크 모드 전환, 연동 계정 재연동/해제, 비밀번호 변경, 로그아웃, 회원 탈퇴

특징이용약관/개인정보처리방침 진입점 포함

✓12. 이용약관/개인정보처리방침 페이지신규

기능이용약관, 개인정보처리방침, 만 14세 미만 가입 제한 등 법적 고지사항 열람

특징회원가입 페이지와 설정 페이지 양쪽에서 진입 가능해야 함 (법적 필수 페이지)

4핵심 기능 정의

필수 기능 (MVP)

  • Riot API 연동 전적 조회: 게임 종류, 진행 시간, 방금 전/며칠 전, 승패 여부 표시
  • 상세 게임 데이터: 챔피언, KDA, 딜량 그래프, 아이템 빌드, 룬 정보 제공
  • 계정 연동 & 소통: 앱 계정과 Riot ID 1:1 매핑, 전적 피드 공유 및 댓글 작성
  • Riot ID 인증 방식: 단순 소환사명 입력은 타인 계정 도용 위험 → 가능하면 RSO(Riot Sign-On) OAuth 연동으로 본인 인증
  • 리전(서버) 처리: Riot API 리전별 엔드포인트(KR/NA/EUW 등) 라우팅, 1차 개발은 KR 서버로 한정

부가 기능 (소셜 및 편의)

  • 전적 감정 표현: 좋아요/싫어요 및 롤 전용 반응('캐리', '버스', '훈수필요' 등)
  • 전적 피드백/댓글 시스템: 시간대별 플레이에 대한 훈수/칭찬 댓글
  • 친구 하이라이트 뱃지: 최근 24시간 최고 딜량 / 최고 KDA 달성자 메인 상단 노출
  • 승급/티어 알림: 친구 티어 변동 시 알림 및 피드 뱃지 생성
  • 알림 종류: 팔로우 · 댓글/피드백 · 좋아요/감정표현 · 승급/티어 알림 (알림 페이지에서 통합 조회)

정책/보안 기능 (필수) 신규

  • 신고/차단 기능: 부적절한 댓글·스팸 게시물 신고, 유저 차단(차단 시 상호 비노출)
  • 공개범위 설정: 전적 공유 시 전체공개/친구공개/비공개 선택
  • Riot API 정책: Development Key는 24시간마다 만료 → 정식 운영 전 Production Key 신청 필요, Rate Limit 고려한 캐싱/갱신 주기 설계

5모바일 UI 특징

네비게이션 (하단 탭 바)

홈(피드)검색+ 전적공유마이페이지

알림(벨) 아이콘은 하단 탭이 아닌 상단 앱 바 우측에 배치, 읽지 않은 알림 개수 뱃지 표시

  • 전적 공유하기(+) 버튼은 하단 탭 바 중앙에 플로팅 형태로 강조 배치
  • 전적 카드의 '댓글/피드백 쓰기' 및 '감정표현' 버튼은 카드 하단 영역에 배치
  • 터치 영역 크기: 최소 44x44pt 이상 확보
  • 세로/가로 모드: 세로 모드 전용 (Portrait Only)
  • 빈 상태(Empty State) / 오류 상태 UI 신규 — 친구 없음, 전적/검색 결과 없음, 존재하지 않는 소환사명, API 장애 시 각각 안내 문구와 재시도/행동 버튼 제공

6개발 우선순위

1차 개발 (기본 기능 - MVP)

  • 이메일 회원가입/로그인 및 Riot ID 연동, 만 14세 미만 가입 제한 검증(생년월일 입력)
  • 이용약관/개인정보처리방침 페이지 제공 및 회원가입 시 동의 절차
  • Riot API 연동: 유저 검색, 최근 매치 목록 및 상세 전적 조회 (KR 서버, Development Key)
  • 내 최근 매치를 선택해 피드(게시물)로 등록하는 기능 (공개범위 선택 포함)

2차 개발 (소셜 & 소통 기능)

  • 친구 검색, 팔로우/즐겨찾기 기능
  • 메인 페이지: 팔로우한 친구들의 전적 카드 자동 피드 구성
  • 전적 카드별 감정 표현 및 피드백(댓글) 작성/조회 기능
  • 신고/차단 기능 및 알림 페이지(팔로우·댓글·좋아요 알림) 구현

3차 개발 (고도화 및 편의기능)

  • 소셜 로그인(구글, 카카오 등) 추가
  • 댓글/좋아요/승급 시 푸시 알림 기능
  • 친구 간 주간 KDA/딜량 랭킹(리더보드) 페이지 추가
  • Riot Production API Key 신청 및 전환, 설정 페이지 고도화

7예외 처리 및 서비스 정책 신규

  • 전적 조회 예외 상황: 존재하지 않는 소환사명 검색, 비공개 전적 조회 시도, Riot API 장애/타임아웃 시 안내 메시지와 재시도 동작 정의 필요
  • 개인정보 및 연령 제한: 만 14세 미만 가입 제한 검증 절차(생년월일 입력) 및 개인정보처리방침·이용약관 페이지 제공 (법적 필수 요건)
  • Riot Games API 정책 준수: 공식 API 이용약관 및 브랜드/상표 가이드라인 준수 (로고·이미지 무단 사용 금지, 비공식 서비스 고지 문구 필요 여부 확인)
  • 커뮤니티 운영 정책: 신고 누적 시 게시물/댓글 자동 숨김 또는 운영자 검토, 반복 신고 대상 유저 제재 기준 수립

# 모바일 서비스 UI 기획서

## 1. 서비스 기본 정보

- **서비스 이름**: our.gg
- **서비스 주제**: 우리들의 리그 오브 레전드 전적을 공유하고 소통하는 미니 SNS 앱
- **핵심 가치**: 단순 전적 조회를 넘어, 친구들의 전적 피드를 보고 피드백(훈수), 감정 표현, 플레이 소감을 공유하는 커뮤니티 형성
- **타겟 사용자**: 리그 오브 레전드를 즐기며 친구들과 플레이 경험을 공유하고 싶어 하는 모든 연령대 유저 (단, 만 14세 미만 가입 제한)
- **서비스 형태**: 모바일 앱 (세로 모드 전용, iOS/Android 대응 여부는 개발 단계에서 결정)
- **지원 서버(리전)**: 1차 출시는 KR(한국) 서버 기준. Riot API는 리전별로 엔드포인트가 다르므로 NA/EUW 등 해외 서버 지원은 추후 확장 항목으로 별도 검토

## 2. 디자인 컨셉

- **메인 색상**: `docs/미니 SNS 프로젝트/color-theme.json` (Primary: 그린 계열 `#4C662B` 기반 Material 테마)
- **승패 Accent 색상**: 위 JSON에는 승/패를 구분하는 블루·레드 톤이 별도로 정의되어 있지 않아 아래와 같이 보강 필요
  - 승리(Win): 블루 계열 Accent 신규 추가 (예: `#3B78E7` / 다크모드 `#A9C6FF`) — 테마의 primary(그린)와 구분되는 색으로 승리 카드에만 사용
  - 패배(Lose): JSON에 이미 정의된 error 색상 재사용 (라이트 `#BA1A1A` / 다크 `#FFB4AB`) — 별도 색을 새로 만들지 않고 기존 에러 컬러를 패배 Accent로 겸용
- **보조 색상**: 다크 모드 기반 배경 (Dark Charcoal / Off-White). 라이트 모드 제공 여부 결정 필요 — `color-theme.json`에는 light/dark 스킴이 모두 존재하므로, 기본은 다크모드로 하되 라이트모드도 함께 지원할지 1차 개발 범위에서 확정
- **타이포그래피/아이콘**: 전적 숫자(KDA, 딜량 등) 가독성을 위한 고정폭 숫자 폰트 또는 tabular-nums 스타일 적용, 게임 감성에 맞는 라인 아이콘 스타일 사용 (참고 사이트와 톤 일치)
- **전체 분위기**: 깔끔하고 전문적인 전적 데이터 시각화 + 밝고 친근한 소셜 커뮤니티 느낌
- **참고 사이트**: OP.GG, Your.gg, FOW.lol

## 3. 필요한 페이지 목록

- [x] **1. 로그인/회원가입 페이지**
  - 기능: 이메일+비밀번호 로그인/회원가입, 자동 로그인(토큰 저장), Riot ID (소환사명+태그, 예: `Hide on bush#KR1`) 연동 및 인증
  - 특징: 만 14세 미만 가입 제한(생년월일 입력 후 서버에서 검증), 가입 시 내 롤 계정을 매핑하여 서비스 내 활동 기반 마련, 로그인 성공 시 메인 피드로 이동, 회원가입 완료 전 이용약관/개인정보처리방침 동의 절차 포함

- [x] **2. 메인 페이지 (홈 / 피드 화면)**
  - 기능: 상단 전적 검색창, 팔로우/즐겨찾기한 친구들의 최근 게임 전적 피드(세로 스크롤)
  - 특징: 친구가 게임을 마치면 전적 카드가 피드 형태로 자동 업데이트, 승/패 배경색 구분, 요약 데이터(KDA, 딜량, 킬관여율) 및 좋아요/댓글 수 표시, 피드가 비어있을 때(팔로우한 친구 없음/최근 전적 없음) 안내 문구와 친구 찾기 유도 버튼 표시

- [x] **3. 게시물 목록 페이지 (전적 탐색/모아보기)**
  - 기능: 전체 공개된 유저들의 '인생 경기' 또는 '피드백 요청' 매치 모아보기, 카테고리 필터(솔로랭크/자유랭크/칼바람)

- [x] **4. 게시물 상세 페이지 (매치 상세 + 피드백/댓글)**
  - 기능: 특정 매치 10인 전체 전적(딜량 그래프, 아이템 빌드, 룬, 킬관여율), 댓글/피드백 작성 및 조회

## 4. 핵심 기능 정의

### 필수 기능 (MVP)
- Riot API 연동 전적 조회: 게임 종류(솔랭/자랭/칼바람 등), 진행 시간, 방금 전/며칠 전, 승패 여부 표시
- 상세 게임 데이터: 챔피언, KDA, 딜량 그래프, 아이템 빌드, 룬 정보 제공
- 계정 연동 & 소통: 앱 계정과 Riot ID 1:1 매핑, 내 전적 피드 공유 및 댓글 작성 기능
- Riot ID 인증 방식: 단순 소환사명 입력만으로는 타인 계정 도용/허위 연동이 가능하므로, 가능하면 RSO(Riot Sign-On) OAuth 연동을 통해 본인 계정임을 인증 (MVP 단계에서 RSO 적용이 어렵다면, 최소한 "연동" 단계에서 명확히 정책 결정 필요)
- 리전(서버) 처리: Riot API 리전별 엔드포인트(KR/NA/EUW 등)에 맞춘 라우팅. 1차 개발 범위는 KR 서버로 한정

### 부가 기능 (소셜 및 편의)
- 전적 감정 표현: 게임 카드에 좋아요/싫어요 및 롤 전용 반응('캐리', '버스', '훈수필요' 등) 남기기
- 전적 피드백/댓글 시스템: 특정 게임의 시간대별 플레이에 대해 훈수나 칭찬 댓글 남기기
- 친구 하이라이트 뱃지: 최근 24시간 동안 친구 중 최고 딜량 / 최고 KDA 달성자 메인 상단 노출
- 승급/티어 알림: 즐겨찾기한 친구의 티어 변동(승급/승단) 시 알림 및 피드 뱃지 생성
- 알림 종류: 팔로우 알림, 댓글/피드백 알림, 좋아요·감정표현 알림, 승급/티어 알림 (알림 페이지에서 통합 조회)

### 정책/보안 기능 (필수) *(신규 추가)*
- 신고/차단 기능: 부적절한 댓글, 악성 훈수, 스팸 게시물 신고 및 특정 유저 차단(차단 시 서로의 게시물/댓글 비노출)
- 공개범위 설정: 전적 공유 시 전체공개/친구공개/비공개 선택 (게시물 작성 페이지에서 설정)
- Riot API 정책 관련 유의사항: Development API Key는 24시간마다 만료되므로 정식 서비스 운영 전 Riot Production API Key 신청 절차 필요, API Rate Limit(요청 제한)을 고려한 데이터 캐싱/갱신 주기 설계 필요

## 5. 모바일 UI 특징

- **네비게이션**: 하단 탭 바 (Bottom Navigation Bar)
  - `[홈(피드)] | [검색] | [+ 전적공유] | [마이페이지]`
  - 알림(벨) 아이콘은 하단 탭이 아닌 상단 앱 바 우측에 배치, 읽지 않은 알림 개수 뱃지 표시
- **주요 버튼 위치**:
  - 전적 공유하기(+) 버튼은 하단 탭 바 중앙에 플로팅 형태로 강조 배치
  - 각 전적 카드의 '댓글/피드백 쓰기' 및 '감정표현' 버튼은 카드 하단 영역에 배치
- **터치 영역 크기**: 모바일 터치 편의성을 위해 최소 44x44pt 이상 확보
- **세로/가로 모드**: 세로 모드 전용 (Portrait Only)
- **빈 상태(Empty State) / 오류 상태 UI** *(신규 추가)*: 팔로우한 친구가 없을 때, 전적/검색 결과가 없을 때, 존재하지 않는 소환사명일 때, Riot API 장애·타임아웃일 때 각각 안내 문구와 재시도/다음 행동 버튼(예: "친구 찾아보기", "다시 시도") 제공

## 6. 개발 우선순위

### 1차 개발 (기본 기능 - MVP)
- 이메일 회원가입/로그인 및 Riot ID 연동, 만 14세 미만 가입 제한 검증(생년월일 입력)
- 이용약관/개인정보처리방침 페이지 제공 및 회원가입 시 동의 절차
- Riot API 연동: 유저 검색, 최근 매치 목록 및 상세 전적 조회 (KR 서버 기준, Development Key로 개발 진행)
- 내 최근 매치를 선택해 피드(게시물)로 등록하는 기능 (공개범위 선택 포함)

### 2차 개발 (소셜 & 소통 기능)
- 친구 검색, 팔로우/즐겨찾기 기능
- 메인 페이지: 팔로우한 친구들의 전적 카드 자동 피드 구성
- 전적 카드별 감정 표현 및 피드백(댓글) 작성/조회 기능
- 신고/차단 기능 및 알림 페이지(팔로우·댓글·좋아요 알림) 구현

### 3차 개발 (고도화 및 편의기능)
- 소셜 로그인(구글, 카카오 등) 추가
- 댓글/좋아요/승급 시 푸시 알림 기능
- 친구 간 주간 KDA/딜량 랭킹(리더보드) 페이지 추가
- Riot Production API Key 신청 및 전환, 설정 페이지(알림 on/off, 다크모드 전환 등) 고도화

## 7. 예외 처리 및 서비스 정책 *(신규 추가)*

- **전적 조회 예외 상황**: 존재하지 않는 소환사명 검색, 라이엇 개인정보 설정으로 비공개된 전적 조회 시도, Riot API 장애/타임아웃 발생 시 각각의 안내 메시지와 재시도 동작 정의 필요

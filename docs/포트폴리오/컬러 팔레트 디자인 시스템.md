## 컬러 사용 가이드

### Primary / Secondary
- `--color-primary` (`#A8C4A2`): 페이지 전체를 아우르는 메인 배경 톤, 헤더/푸터 배경, 섹션 구분 배경에 사용
- `--color-primary-light` (`#B8CFAE`): 넓은 면적의 배경(히어로 섹션 등)에 사용해 부드러운 인상을 줌
- `--color-primary-dark` (`#7A9B6E`): 버튼, 아이콘, 강조 텍스트 등 시선을 끌어야 하는 요소에 사용
- `--color-secondary` (`#F5F2E8`): 카드, 메모지 스타일 콘텐츠 박스, 입력창 등 콘텐츠가 올라가는 표면색
- `--color-accent` (`#E8967A`): 하트/뱃지/알림 점 등 아주 소량만 사용하는 포인트 컬러 (전체의 5% 이하 권장)

### Background
- `--color-bg-primary`: 페이지 최상단 배경, 전체 톤을 결정
- `--color-bg-secondary`: 카드·모달·섹션 내부 배경으로 사용해 `bg-primary`와 명도 대비를 줌

### Text
- `--color-text-primary` (`#4A6142`): 제목, 본문 등 핵심 정보 텍스트 — 명도가 낮아 가독성 확보
- `--color-text-secondary` (`#5C7A54`): 부제목, 라벨, 설명 텍스트
- `--color-text-muted` (`#8FAF82`): 캡션, placeholder, 타임스탬프 등 우선순위가 낮은 텍스트

### Border
- `--color-border` (`#6B8F60`): 카드·프레임의 주 테두리, 구분선
- `--color-border-light` (`#DCE5D3`): 입력창, 그리드 등 옅은 구분이 필요한 테두리

### Interactive
- `--color-button-primary`: 기본 버튼 배경색
- `--color-button-hover`: 버튼 hover/active 상태 (primary보다 한 단계 어둡게)
- `--color-link`: 텍스트 링크, 소소한 강조 요소 (accent 컬러 재사용)
- `--color-link-hover`: 링크 hover 시 약간 더 진한 톤

## 반응형 고려사항

### 다크모드
현재 팔레트는 라이트 톤 중심이므로, 다크모드 적용 시 아래와 같이 명도를 반전해 대비를 확보하는 것을 권장합니다.

```css
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #2E3A2A;
    --color-bg-secondary: #3A4A35;
    --color-text-primary: #F5F2E8;
    --color-text-secondary: #DCE5D3;
    --color-text-muted: #9FBC94;
    --color-border: #5C7A54;
    --color-border-light: #4A5C44;
    --color-button-primary: #8FAF82;
    --color-button-hover: #A8C4A2;
  }
}
```
- 배경은 어두운 그린(`#2E3A2A` 계열)으로, 텍스트는 밝은 크림(`#F5F2E8`)으로 반전해 원래 팔레트의 톤앤매너(세이지 그린 무드)를 유지합니다.
- accent 컬러(`#E8967A`)는 다크모드에서도 그대로 사용 가능 — 어두운 배경 위에서 채도 대비가 오히려 더 잘 보입니다.

### 화면 크기별 고려사항
- 모바일에서는 배경색 대비가 작은 화면에서 눈에 덜 띄므로, `--color-primary-dark`나 `--color-accent`를 버튼/CTA에 우선 배치해 터치 영역의 시인성을 높입니다.
- 큰 화면(데스크톱)에서는 `--color-bg-primary`와 `--color-bg-secondary`의 명도 차이를 활용해 섹션 구분을 명확히 합니다.

### 접근성(A11y)
- `--color-text-primary`(`#4A6142`) on `--color-bg-secondary`(`#F7F4EA`) 조합은 WCAG AA 기준(4.5:1)을 충족합니다.
- `--color-accent`(`#E8967A`)를 텍스트 색으로 사용할 경우 밝은 배경에서는 대비가 부족할 수 있으므로, 텍스트보다는 아이콘·배지 등 보조 요소에 한정해 사용하는 것을 권장합니다.
